# 🧰 AI-Toolbox
Personal hub for AI skills, prompts, rules, and configs.

## 📦 Contents
- **`.agents/skills/`** — Agent skills & workflows
- **`prompts/`** — Reusable prompt templates
- **`rules/`** — Coding standards & agent rules
- **`mcp/`** — MCP server configurations

## ⚡ Quick Copy (PowerShell)
```powershell
# Global (all IDEs):
Copy-Item ".\.agents\skills\*" "$HOME\.agents\skills\" -Recurse -Force
# Project-level:
Copy-Item ".\.agents\skills\*" "..\<project>\.agents\skills\" -Recurse -Force
```
